# 雀灵 · 翻译与朗读交互演示

在线访问：https://woaizou-eng.github.io/queling-translation-demo-1030/

从原 Sites 演示迁移的静态网页，保留原有界面及交互。

## 功能

- 划选英文台词，查看预置中文译文。
- 保留本次任务中的翻译历史，支持复制译文。
- 使用浏览器和设备提供的英文语音朗读原文。
- 模拟翻译失败与重试、切换任务和重置演示。

## 演示范围

译文为预置示例，不连接在线翻译服务；视频为静态画面；朗读效果取决于设备及浏览器的语音支持。

## 本地查看

在项目目录运行 `python3 -m http.server 8000`，打开 http://localhost:8000/。

GitHub Pages 从 `main` 分支根目录部署，无需构建或安装依赖。
